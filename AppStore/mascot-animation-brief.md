# Mascot animation set — order brief (copy-paste to the animator)

Use this text when ordering on Fiverr/Upwork. Search terms to find the right
sellers: "lottie character animation", "2D character rigging lottie",
"telegram sticker animation". Pick one whose portfolio shows CUTE CHARACTERS
(animals with faces and moods), rating 4.9+, and ask to see a Lottie JSON
sample from a past job before ordering.

---

## The brief (paste from here down)

I am building an iPhone messaging app and need a small mascot character,
animated, delivered as Lottie JSON files. Style reference: the Telegram duck
(a cute character with moods that appears on empty screens). I need my own
original character, NOT a copy of the duck.

**Character:** a cute baby camel (chubby, big eyes, friendly — sticker-like,
bold outlines). I'd like to see 2-3 character design sketches first before
animation starts.

**Deliverables: 5 animations of this character, each a seamless loop:**

1. **Welcome** — the camel waves hello, then looks around curiously
   (for the "no chats yet" screen)
2. **Calling** — the camel holds an old-style telephone to its ear, happy
   (for the empty calls screen)
3. **Searching** — the camel looks through a magnifying glass, left and right
   (for the search screen)
4. **Sleeping** — the camel sleeps curled up in/next to a cardboard box
   (for the empty archive screen)
5. **Watching** — the camel peeks out and blinks, waiting
   (for the "no story views yet" screen)

**Technical requirements (important):**
- Lottie JSON format, exported with Bodymovin/LottieFiles plugin from After Effects
- Fully vector (no embedded raster images), transparent background
- Square composition 512x512, 60fps or 30fps, each loop 2-4 seconds
- Each JSON file under 150 KB
- Must render correctly in lottie-ios (Airbnb player) — please test before delivery
- Deliver: the 5 .json files + the After Effects source files (.aep)

**Rights:** full commercial rights transfer — the character and animations
become my property, exclusive (you may show them in your portfolio only).

**Process:** character sketches first → I approve one → 1 animation as a
test → I approve → the remaining 4. Two revision rounds included per animation.

---

## Budget guidance (for you, not the seller)
- Realistic total: $150-500 for the set from a good Fiverr seller.
- If a seller quotes under $100 for all 5, quality will likely be poor — skip.
- Pay per milestone (sketches → first animation → rest), never all upfront.
- The exclusive-rights + source-files part is non-negotiable; some sellers
  charge extra for it — that's normal and worth it.

## What happens after delivery
Send me the 5 JSON files. I add the Lottie player to the app (half a day) and
wire each animation into its screen — the app is already structured for this
(one shared EmptyStateView).
